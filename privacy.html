Privacy Policy

Last updated: September 25, 2026 · Operator: Salih Tekin

Talonaris Shorts Studio ("the tool") is an internal tool used only by its operator to publish videos to the operator's own YouTube channels. This policy explains what data the tool handles when it uses YouTube API Services.

YouTube API Services

The tool uses YouTube API Services. Using the tool means you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What data the tool accesses

  • OAuth credentials for the operator's own Google account, granted through Google's consent screen, with these scopes: upload videos (youtube.upload), read channel information (youtube.readonly) and read channel analytics (yt-analytics.readonly).
  • Channel and video information for the operator's own channels: video IDs, titles, publication status and schedule.
  • Aggregated analytics for the operator's own videos, such as views, watch time and average view duration. These figures are aggregated by YouTube and contain no personal information about individual viewers.

The tool does not access, collect or store personal data about viewers, commenters or any other YouTube user.

How the data is used

The data is used only to upload and schedule the operator's videos and to measure how those videos perform, so future videos can be improved. It is not used for advertising, profiling or any other purpose.

Storage and security

OAuth tokens and analytics data are stored on a private server controlled by the operator. Credential files can be read only by the service account that runs the tool, and tokens are never written to logs. Analytics data is kept for up to 24 months and then deleted. Tokens are deleted when access is revoked.

Sharing

No data is sold, rented or shared with third parties. Data is sent only to Google/YouTube, as needed to perform the actions described above.

Revoking access

Access can be revoked at any time on the Google security settings page. After access is revoked, the tool can no longer act on the account, and stored tokens are deleted.

Cookies

This website uses no cookies, analytics or trackers.

Changes

If this policy changes, the new version will be published on this page with an updated date.
